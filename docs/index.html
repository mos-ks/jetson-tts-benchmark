Jetson TTS Benchmark

Open text-to-speech models on an 8 GB Jetson Orin Nano Super, measured the way a voice assistant would use them: how soon the first audio comes, how many times faster than real time it speaks, how much memory and power it takes, and how natural it sounds. Every model says the same six lines, three in English and three in German; the ones that clone a voice all speak with the same designed reference voice.

The designed reference voices

Designed from a description with Qwen3-TTS 1.7B VoiceDesign (once, on a desktop GPU), then the same voice in German by cloning the English clip with Qwen3-TTS 1.7B Base. No real person's voice. The cloning models in this benchmark speak with Warm.

Warm

“A warm, friendly young woman in her twenties. Soft, bright and gently playful, with a smile in her voice. Calm, encouraging and clear, at a relaxed natural pace. Cozy and caring, never childish, never breathy or whispery.”

How it was measured

Board. Jetson Orin Nano Engineering Reference Developer Kit Super, 8 GB (7.4 GiB usable), JetPack 6.2 (L4T R36.4.3), CUDA 12.6, Python 3.10, 6 CPU cores, power mode MAXN SUPER. The board was serving other work at the time (a web backend and an idle Ollama), as it would in use.

Each model in its own virtual environment (GPU runs with PyTorch 2.8 or onnxruntime-gpu 1.24 from NVIDIA's Jetson AI Lab index), loaded once per language, warmed up once, then each line spoken once and timed. One run at a time, and stopped if the board's free memory falls below 800 MB.

Threads. The CPU runs use all 6 cores. Pocket TTS was also run with 1, 2 and 4 threads: the 100M model stays at 0.51 to 0.56× at any count, and the small English model is fastest on one thread (1.23×, against 1.05× on six).

Too big. A run is stopped when the board's free memory falls below 800 MB. OmniVoice, Qwen3-TTS 0.6B, Chatterbox and MOSS-TTS-Nano on the GPU (also with ONNX Runtime's lean arena settings) each reached that floor while loading or warming up, starting from 4.3 to 5.2 GB free: on an 8 GB Orin Nano they need the board nearly to themselves.

Realism is predicted, not a listening test: UTMOS (utmos22_strong) on every clip. It rewards clean, neutral read-aloud speech, so a plain preset voice can outscore a livelier one, and it says nothing about whether a voice sounds like anyone in particular. Listen to the clips to judge for yourself.
